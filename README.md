# nanokeydj

KORG nanoSERIES2 の3台（nanoKONTROL2、nanoPAD2、nanoKEY2）で操作する、ブラウザ上の2デッキ DJ アプリです。Web MIDI API で入力を受け、Web Audio API で再生とミキシングを行います。

## 動かし方

```sh
npm install
npm run dev
```

Chrome（または Edge）で http://localhost:5173 を開きます。

1. 初回に MIDI の使用許可を求められるので許可します。
2. ブラウザの仕様で、音声は画面を一度クリックするまで鳴りません。MIDI の操作は「ユーザー操作」とみなされないため、先にページのどこかをクリックしてください。
3. 「曲を読み込む」かドラッグ＆ドロップでローカルの音声ファイルを読み込みます。外部ファイルがなくても、「デモ曲」で動作を試せます。

Firefox も Web MIDI に対応していますが、動作確認は Chrome で行っています。Safari は Web MIDI に対応していません。

## 実機で最初に確認すること

nanoSERIES2 の CC 番号とノート番号は、出荷時設定を前提にした初期値です。実機で外れている可能性があるため、最初に次の順で確認してください。

1. 3台を USB 接続し、画面上部の「MIDI モニター」で3台が「接続中」になることを確認します。
2. つまみやパッドを動かし、モニターに出る CC 番号とノート番号を、下の初期割り当てと照らします。
3. 外れていたら「MIDI 割り当て」を開き、対象の行で「学習」を押してから実機を操作します。結果はブラウザに保存されます。
4. nanoPAD2 は「ホットキューを順に学習」で、16 個のパッドを順に押すだけで割り当てられます。

## 初期割り当て

| 機器 | 割り当て |
|---|---|
| nanoKONTROL2 フェーダー1〜6 | A 音量、B 音量、クロスフェーダー、マスター、A テンポ、B テンポ |
| nanoKONTROL2 ノブ1〜4、5〜8 | Deck A と Deck B の Hi / Mid / Low / Filter |
| nanoKONTROL2 S / M / R（ch1、ch5） | Deck A と Deck B の Play / Cue / Sync |
| nanoKONTROL2 Play、Cycle | フォーカスデッキの再生、ループ解除 |
| nanoKONTROL2 Track ◀ ▶ | フォーカスデッキを A / B に切り替え |
| nanoKONTROL2 Marker Set（押している間） | ホットキュー削除モード。このまま該当のパッドを押すと消える |
| nanoPAD2 パッド1〜8、9〜16 | Deck A と Deck B のホットキュー1〜8 |
| nanoKEY2 白鍵 C D E F G A B | フォーカスデッキのビートループ（½、1、2、4、8、16、32 拍）。同じ長さをもう一度押すと解除 |
| nanoKEY2 黒鍵 C# D# F# G# | ビートジャンプ（-8、-4、+4、+8 拍）。A# はループ解除 |
| nanoKEY2 ピッチベンドボタン | フォーカスデッキの nudge（±5 %、押している間だけ） |

nanoKEY2 の鍵盤はオクターブを無視した音名で割り当てているので、オクターブシフトを使っても割り当てはずれません。

## 操作の挙動

- **Cue** は CDJ 方式です。再生中に押すとキューポイントに戻って止まります。止まっていてキューポイント上にいるときは、押している間だけ再生します。キューポイントから離れているときは、その位置を新しいキューポイントにします。
- **ホットキュー**は、空いていれば今の位置に打ち、打ってあれば飛んで再生します。右クリック（または削除モード）で消せます。
- **Sync** は相手デッキの実効テンポに合わせます。両方が再生中なら、拍の位相も近いほうへ位置を動かして揃えます。
- **テンポフェーダー**は DJ 機器の慣習に合わせ、既定では上が遅く下が速くなります。ミキサーの「上が遅い」で反転できます。レンジは ±6〜50 % から選べます。
- **BPM** は読み込み時にワーカーで自動解析します。半分や倍のテンポを選んだときは、デッキの「½」「×2」で直せます。

## 既知の制限

- フェーダーとノブは絶対値で反映します。起動直後は画面の値と実機の位置が合っていないので、最初に動かした瞬間に音が跳びます。
- キーロック（テンポを変えても音程を保つ機能）はありません。テンポを変えると音程も変わります。
- ヘッドホン Cue（PFL）はありません。ブラウザは1つの `AudioContext` で1つの出力しか扱えません。
- nanoKONTROL2 のボタン LED や、nanoPAD2 の XY パッドは使っていません。
- 手動のループイン・アウトはありません。ビートループだけです。

## 開発

```sh
npm test           # Vitest
npm run typecheck  # tsc
npm run build      # 型検査と本番ビルド
```

構成と設計の経緯は [docs/PLAN.md](docs/PLAN.md) にあります。MIDI のパース、バインディング、再生クロック、各種カーブ、BPM 検出、Deck の状態遷移は DOM と Web Audio から切り離してあり、Node 上のテストで検証しています。
